# Ayush Roy — Portfolio

A responsive personal portfolio made by Ayush Roy, built as a static website and deployed on Vercel.

**Live site:** https://ayush-roy-1901.vercel.app/

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server, for example:

```sh
npx serve .
```

## Project layout

- `index.html` — portfolio markup, styles, interactions, and scroll effects
- `assets/` — hero artwork and racing circuit graphics
- `achievements/` — certificate images shown in the Achievements section
- `ayush-profile.png` — profile photo
- `cv.pdf` — CV opened by the Hire me buttons

The project has no build step or package dependencies. To deploy it on Vercel, import this repository and use the repository root as the project root.
